# Bankor G3 Academy — ملاحظات الإصدار v0.5

## الإضافات المنفّذة
- **مسار تعلم تفاعلي** يقسم 113 درسًا إلى 15 وحدة بحسب ترتيب المحتوى الأصلي، مع عقد للمراحل المكتملة والجارية والقادمة وتحديات للوحدات.
- **تحديد الدرس التالي** من الإنجاز المحفوظ، وليس ترتيب ثابت يظهر بغض النظر عن تقدم المستخدم.
- **اختيار الوحدة** من شريط أفقي. المكتبة العلمية تظل مفتوحة بالكامل، بينما يُفتح تحدي نهاية الوحدة بعد إنهاء دروسها.
- **وضع القراءة الموجّهة** يجزّئ الدرس إلى خطوات مبنية على الفقرات دون إعادة كتابة المحتوى أو فقده، بجانب وضع «المادة كاملة».
- **تحديات وحدات** بأسئلة حقيقية من بنك الأسئلة، واجتياز عند 80%، ومكافأة إتقان واحدة فقط (+40 XP).
- **تحديات دروس مرتبطة بالمادة** من معرّفات الأسئلة المستوردة (عند توفرها)، واجتياز عند 80%، ومكافأة إتقان واحدة فقط (+20 XP).
- يستمر نظام الأسئلة/النتائج/الأخطاء/التخطيط الذكي والإشعارات وهوية بنكور من v0.4.

## البيانات المستوردة
- 113 درسًا، 15 وحدة تعليمية، 895 سؤالًا محفوظًا في JSON دون تعديل نصوص المادة.
- 109 دروس بها ارتباط واحد على الأقل بأسئلة المصدر؛ 4 دروس لا يوجد لها ارتباط مباشر، لذلك لا نختلق لها أسئلة.
- وحدة أساسيات بدون أسئلة مستقلة في البنك: يظهر مسار القراءة لها دون تحدٍ اصطناعي.
- الأسئلة الأصلية تحتاج مراجعة علمية من متخصص قبل نشر التطبيق لمستخدمين آخرين؛ لم تُقدَّم بوصفها مادة رسمية معتمدة.

## المنطق المختبَر
`npm test` يتحقق من:
- صحة تخطيط الأيام والاستثناءات ومراعاة انتهاء وقت الجلسة.
- تجنّب تكرار مكافأة الدرس، ومكافآت إنجاز الخطة.
- توزيع محاكاة 50 سؤالًا وفق ملف المصدر.
- دقة استيراد المسار (15 وحدة، 113 عقدة درس) وانتقال الحالة بعد إكمال درس.
- سلامة تقسيم النص دون فقد محتوى.
- حد النجاح (80%)، وعدم تكرار مكافآت إتقان الدرس والوحدة.
- تطابق تحدي الدرس مع معرّفات الأسئلة المرتبطة به فقط.

## حدود هذا التسليم
- لا يحتوي ZIP على APK أو AAB.
- اختبارات محرك TypeScript نجحت، وفحص TSX النحوي لم يُظهر أخطاء، لكن **لم ينجح تثبيت npm** هنا بسبب تعذر الوصول إلى registry.npmjs.org؛ لذلك لم يتم تشغيل التطبيق في Metro أو اختباره على جهاز Android أو تنفيذ فحص Typescript كامل يشمل React Native.
- الأيقونات البديلة تتغير عندما يعمل كود التطبيق وبحسب دعم الجهاز، ولا نضمن تغير الأيقونة آليًا بينما التطبيق مغلق تمامًا. خاصية تبديل الأيقونة تحتاج **Native Build** لا Expo Go.
- الرسوم المستخدمة موجودة في `assets` ومقتطعة من مرجع شخصية بنكور الثابت؛ الأنيميشن الديناميكي متعدد الإطارات مؤجل لمرحلة لاحقة.

## التشغيل على جهاز المطور
```bash
npm install
npx expo install --fix
npm test
npm start
```
ثم تجربة Android عبر development build. لإخراج نسخة APK بعد إعداد EAS والحساب:
```bash
npx eas-cli build --platform android --profile preview
```

تشغيل التطبيق فعليًا على Android، إصلاح الملاحظات البصرية/الوظيفية من التشغيل، إضافة أنيميشن بنكور الأصلي واختبارات Android end-to-end، وتحسين خوارزمية المراجعة المتباعدة.
