# ملاحظات إصدار Bankor G3 Academy v0.7

## المنفذ
- استرجاع المحاكاة بعد الإغلاق من التخزين المحلي دون إعادة ضبط الوقت.
- إمكانية تغيير الإجابة والتنقل بين الأسئلة وإظهار الأسئلة غير المجابة وتحذير التسليم.
- إصلاح جدولة المراجعة المتباعدة للأخطاء القديمة بعد الإجابة الصحيحة.
- إيقاف إشعارات بنكور من الإعدادات وإلغاء ما هو مجدول.
- خفض تكرار تحديث الساعة في الشاشات غير الموقوتة.

## اختبارات المصدر
- `npm test`: ست مجموعات ناجحة (planner/schedule/quiz/journey/review/quizSession).
- لم تنجح محاولة الحصول على حزم Expo عبر الإنترنت (`EAI_AGAIN`). لا يوجد APK مبني ولا تأكيد بصري أو اختبار Native.

## بعد استعادة الإنترنت
1. `npm install`
2. `npx expo install --fix`
3. `npm run check && npm test`
4. `npx expo start --android` على جهاز فعلي/محاكي.
5. تجربة إغلاق التطبيق أثناء المحاكاة، واسترجاع الإجابات، وانتهاء الوقت بالخلفية، وأذونات الإشعارات.
6. `npx eas-cli build --platform android --profile preview` لإنتاج APK عند تجهيز حساب/صلاحيات EAS.
