# Bankor G3 Academy — ملخص الإصدار v0.6

## المنفذ برمجيًا

1. محرك `src/review.ts`: جدول مراجعة متباعدة للأسئلة المجاب عنها؛ الإجابات الخاطئة مستحقة فورًا والصحيحة بعد فترات 1، 3، 7، 14، 30، 60، 90 يومًا عند استمرار الإجابة الصحيحة. إعادة الإجابة الخاطئة تصفّر عداد النجاح المتتالي.
2. تحديث `src/quiz.ts`: تخزين `reviewCards` داخل سجل الاختبار، مع الحفاظ على `wrongIds` والأسئلة القديمة. الحفاظ على بيانات مكافآت الدروس والوحدات عند التسجيل.
3. تحديث `App.tsx`: بطاقة مراجعات اليوم في الرئيسية، زر المراجعة المستحقة في شاشة التدريبات، وعدادات مراجعة في شاشة الإنجازات. مراجعات اليوم تسحب الأسئلة المستحقة من المحرك الجديد وتدمج الأخطاء القديمة.
4. إضافة احتفال بصري عند إنهاء الدرس: شخصية بنكور المعتمدة + XP + خيار الاستمرار أو اختبار فهم الدرس المرتبط.
5. تحديث `src/notifications.ts`: جدولة تنبيهات محلية لتواريخ المراجعات المعروفة بجانب تنبيهات الجلسات والامتحان، مع الاحتفاظ بحد أقصى تقريبي 58 إشعارًا.

## الاختبارات المنفذة

- `npm test`: PASS؛ 5 مجموعات اختبارات مستقلة (المخطط، الجداول، الامتحانات، المسار، المراجعة الذكية).
- فحص صياغة TS/TSX للأجزاء المحدثة باستخدام TypeScript transpileModule: PASS.
- `npm install`: تعذر بسبب فشل DNS/الشبكة `EAI_AGAIN registry.npmjs.org`؛ لذلك لم ننجز فحص React Native الكامل، ولا Metro، ولا إنشاء APK، ولا اختبار الهاتف.

## حدود تقنية مهمة

- تتجدد المراجعات اليومية تلقائيًا بحسب تاريخ الجهاز عند فتح التطبيق، وتُجدول إشعاراتها من آخر فتح/تقدم عند توفر أذونات النظام. لا يعمل JavaScript تلقائيًا أثناء إغلاق التطبيق تمامًا.
- التحول التلقائي لأيقونة اللانشر يعتمد على API أصلي وقيود النظام، ولا يُضمن حدوثه دون فتح التطبيق.
- خوارزمية 1/3/7/14/30/60/90 قاعدة تعليمية مبسطة وليست نموذج قياس علمي مستقل لقوة الذاكرة.
- المكافآت الحالية غير قابلة للتحويل إلى رصيد أو مدفوعات، والمحتوى مستورد وغير موثّق رسميًا من جهة بنكية.
- لضمان اتساق شخصية بنكور، الصور مقتطعة من المرجع المعتمد، وستحتاج الأصول الموجهة للحركة لتجهيز لاحق.

## التشغيل بعد تنزيل الحزم

```bash
npm install
npx expo install --fix
npm test
npm start
```

لبناء APK تجريبي يتطلب بيئة EAS مؤهلة واتصالًا وحسابًا: `npx eas-cli build --platform android --profile preview`.
