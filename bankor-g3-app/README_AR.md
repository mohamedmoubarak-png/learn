# بنكور | Banker G3 Academy 3.0

**نسخة React Native / Expo أولية قابلة للتطوير (MVP v0.8)**، مبنية على `Banker_G3_app.zip` الذي قدّمه صاحب المشروع. الهوية الأصلية: الصقر **بنكور (Bankor)**.

## ما أُضيف في v0.8 (النسخة الحالية)

- Streak مبني على **إتمام درس أو اختبار حقيقي**، وتذكير يومي خفيف عندما لا توجد مذاكرة مسجلة.
- منع ازدواج تصحيح الاختبار والمكافآت عند تزامن نهاية المؤقت والتسليم.
- فحص آلي كامل للمادة (113 درسًا / 895 سؤالًا) واكتشاف النواقص بدل إخفائها.
- تجهيز GitHub Actions لبناء **Debug APK تجريبي عند الطلب**؛ لم ينفذ البناء الفعلي بعد.
- جميع التفاصيل في `docs/RELEASE_v0.8_AR.md`.

## ما أُضيف في v0.7

- استرجاع الامتحان الموقّت بعد إغلاق التطبيق، والسماح بالتنقل والإجابة، وإصلاح توقيت مراجعة الأسئلة.
- تفعيل/إيقاف تنبيهات بنكور من إعدادات المذاكرة.
- التفاصيل في `docs/RELEASE_v0.7_AR.md`.

## الإضافات الجديدة — v0.6

- **مراجعة ذكية متباعدة Offline**: بعد كل إجابة يتم تحديث بطاقة مراجعة السؤال تلقائيًا. الأسئلة الغلط مستحقة فورًا، أما الصحيحة فتتكرر بعد 1 و3 و7 و14 و30 و60 و90 يومًا عند استمرار الإجابات الصحيحة.
- **الاحتفاظ بالتقدم القديم**: حفظ بيانات المراجعة ضمن `bankor:quiz`، والاحتفاظ بقائمة الأخطاء القديمة عند التحديث من v0.5.
- **بطاقة مراجعات اليوم** على الشاشة الرئيسية، وعرض المستحق والمجدول في شاشة التدريب والإحصائيات.
- **احتفال إنهاء الدرس**: شاشة منبثقة بشخصية بنكور المعتمدة مع XP وزر متابعة المسار أو تحدي فهم الدرس.
- **إشعارات المراجعة المستقبلية**: جدولة تذكير للأيام التي توجد بها أسئلة مستحقة، بالتوقيت المختار في الخطة، بعد السماح للإشعارات.
- **التحقق الآلي**: إضافة اختبار مستقل لمنطق المراجعة وجدولها، واجتياز خمسة ملفات اختبار.

## ما تم تنفيذه

- واجهة عربية Mobile-first فيها شخصية بنكور بتعبيرات: فرح، إنجاز، تشجيع، تركيز، قلق، حزن.
- **113 درسًا** مستخرجًا من المادة العلمية مع حفظ القراءة الجزئية، ومؤقت لا يحتسب وقت التطبيق بالخلفية، وتأكيد الإنجاز.
- **895 سؤالًا** مع الاختيارات والإجابات والتفسير الأصلي المتوفر بالمصدر.
- تدريب سريع (10 أسئلة)، تدريب بحسب 15 موضوعًا، مراجعة الأخطاء، ومحاكاة **50 سؤالًا / 60 دقيقة** بالتوزيع الموجود في `data/meta.json` (35 فني + 15 إلزامي).
- مخطط ذكي يعيد توزيع الدروس المتبقية على الساعات المتاحة **بما فيها ما تبقى من جلسات اليوم الحالي**. لا يغير موعد الهدف من تلقاء نفسه؛ إذا تعذّر تحقيقه يوضح حجم العجز.
- اختيار **موعد الامتحان، ساعته، تاريخ إنهاء المادة، أيام الراحة، جلسات أيام العمل، جلسات عطلة الأسبوع، وجلسات مخصصة لأي يوم** مع قوالب إجازة 4 / 6 / 8 ساعات لمدة 7 أيام.
- تقدير سرعة القراءة من جلسات حقيقية مكتملة، وإعادة حساب الموعد المتوقع عند تغيير الخطة أو التقدم.
- مكافآت XP، قلوب تتجدد يوميًا (تحفيزية ولا تحرم من المذاكرة)، شارات، سجل اختبارات، مهام يومية، سلسلة أيام.
- إشعارات محلية بمواعيد الجلسات، وتنبيه عند العجز المتوقع، وتذكير عشية الامتحان.
- محاولة تغيير أيقونة Launcher عندما تتغير حالة بنكور عبر إضافة `expo-awesome-app-icon` في **نسخة Native**.
- حفظ الحالة محليًا باستخدام `AsyncStorage`؛ لا يلزم حساب ولا خادم ولا اتصال لاستخدام المادة.

## طريقة التشغيل

يتطلب Node.js 22+ مع npm وAndroid Studio أو جهاز Android.

```bash
npm install
npx expo install --fix
npm run test
npm start
```

ثم استخدم **Development Build** لتجربة التطبيق على Android؛ دعم Expo Go لإصدار SDK 58 قد لا يكون متاحًا على أجهزة المتجر حتى تكتمل عملية طرحه. **تبديل الأيقونة الأصلية يتطلب بناءً Native ولا يعمل في Expo Go.**

**بناء APK للتثبيت التجريبي بعد تسجيل دخول Expo / EAS:**

```bash
npx eas-cli login
npx eas-cli build --platform android --profile preview
```

**بناء AAB للنشر:**

```bash
npx eas-cli build --platform android --profile production
```

يتطلب البناء السحابي اتصال إنترنت وحساب EAS وتوفير بيانات التوقيع اللازمة.

## بناء APK آخر عبر GitHub Actions

بعد رفع ملفات المشروع لمستودع GitHub، افتح **Actions → Build Bankor Android APK → Run workflow**. إذا نجح، حمّل `app-debug.apk` من **Artifacts**. لا يحتاج المسار حساب EAS، لكنه **غير مجرّب حتى الآن** ويتطلب وصول GitHub إلى npm/Gradle. راجع `docs/RELEASE_v0.8_AR.md`.

## الاختبارات

## حدود النسخة الحالية (مهمة)

- **ليست APK أو AAB مبنيًا بالفعل**؛ الملفات هنا هي الشفرة المصدرية وموارد التطبيق. لم يتم إجراء اختبار فعلي على هاتف أو تشغيل Metro/EAS بسبب عدم توفر تثبيت الحزم/بيئة Android هنا.
- تبديل أيقونة التطبيق خارجيًا يحصل عندما يعمل JavaScript ويُرسل الطلب للطبقة الأصلية، وعلى Android قد يتأجل إلى الخلفية. **لا نضمن تغير الأيقونة وحده والموبايل مغلق أو التطبيق لم يُفتح لأيام.** الإشعارات المجدولة تشتغل دون تشغيل التطبيق ما دامت أذن النظام بذلك ولم يمنعها توفير البطارية.
- إعادة التخطيط تُنفّذ عند فتح التطبيق أو حدوث تغيير فيه؛ التنبؤ والتوزيع الكامل في الخلفية بشكل مستقل يتطلب تطويرًا إضافيًا باستخدام مهام أصلية أو خادم وإشعارات Push.
- صور بنكور الحالية صور 2D منفصلة وليست رسوم Rive/Lottie متحركة؛ احتفال النسخة الحالية نافذة Fade مع صور ثابتة، وليس رسوم Rive/Lottie متحركة.
- المحتوى مستورد من ملفات المصدر وليس نسخة مؤكدة رسميًا من البنك؛ يجب **مراجعة التعليمات والمادة العلمية والأسئلة** قبل الاعتماد عليها بقرار مهني.
- المصدر يتضمن أسئلة Camunda دون دروس موازية لها. أسئلة الموضوع متاحة في الاختبارات؛ لم نخترع مادة علمية غير موجودة.
- مواعيد جلسات اليوم الواحد يجب أن تبدأ وتنتهي في نفس اليوم، بحد أقصى 14 ساعة/يوم. يمكن تخصيص يوم معين أو مسحه.
- لا توجد مزامنة حسابات سحابية أو لوحة إدارة محتوى في النسخة الأولية.
- شاشات الترحيب أُضيفت في الشفرة لكن لم تُشغّل أو تُختبر على جهاز Android فعلي في هذه البيئة.
- هوية بنكور تعتمد على الصور المستخرجة من مرجع المستخدم؛ ليست مجموعة ملفات رسوم متجهة كاملة بعد.

## بعد أول تثبيت

1. افتح **خطتي** وحدد تاريخ الامتحان وتاريخ الانتهاء المستهدف. مبدئيًا سيقترح التطبيق موعد امتحان 30 أكتوبر 2026 إذا كان في المستقبل، وإلا تاريخًا افتراضيًا بعد أسبوعين.
2. اختر جلسات أيام العمل والإجازات؛ لو إجازة الآن اختر **6 أو 8 ساعات يوميًا** لسبعة أيام ثم عدّل الأيام الفردية.
3. اضغط **احفظ الخطة** ثم **فعّل إشعارات المذاكرة** واسمح بالإشعارات من الجهاز.
4. افتح **مساري** للبدء، أو **المكتبة** لاختيار موضوع، أو **اختبرني** للمحاكاة.

إصدار المصدر: `0.7.0` — 25 أكتوبر 2026.


## تحديث v0.7 — حماية المحاكاة والمراجعة والتحكم في التذكيرات

- **الاستكمال بعد إغلاق التطبيق**: يحفظ بنكور الاختبار الجاري محليًا بما فيه ترتيب الأسئلة، اختياراتك، رقم السؤال الحالي، والوقت الأصلي لبدء المحاكاة، ويعيد فتحه تلقائيًا عند العودة. الوقت **لا يبدأ من الصفر** بعد إعادة التشغيل.
- **تحسين محاكاة G3**: شريط تنقل مرقم يقفز لأي سؤال، تعديل الإجابة حتى التسليم، عداد للأسئلة غير المجابة، وتحذير تأكيدي لو طلبت التسليم قبل إجابة كل الأسئلة.
- **حل مشكلة المراجعات**: السؤال الذي كان خطأ ثم أُجيب عنه صحيحًا لا يستمر في قائمة مراجعة اليوم إذا حُدد له موعد في المستقبل.
- **إيقاف تنبيهات بنكور**: زر لإلغاء تذكيرات بنكور المجدولة فقط، دون إلغاء إشعارات تطبيقات أخرى.
- **تحسين الأداء**: تحديث الساعة كل دقيقة في الشاشات العادية، وكل ثانية أثناء المحاكاة الموقوتة، بدل إعادة حساب خطة المذاكرة 60 مرة في الدقيقة طوال الاستخدام.
- **المحتوى لم يتغير**: 113 درسًا و895 سؤالًا، مع المحافظة على الهوية البصرية لبنكور وصوره المعتمدة.

### اختبارات الإصدار الجديد

`npm test` — ست مجموعات اختبارات منطقية ناجحة، بما فيها اختبار جديد لسلامة استرجاع الاختبار والوقت المتبقي والتحقق من البيانات المفسودة، واختبار لمنع عودة الأسئلة المستقبلية إلى قائمة مراجعة اليوم. هذه **اختبارات منطق** وليست إثباتًا لاجتياز تشغيل Android الفعلي.

### الوضع الحقيقي للبناء

لم يتم إخراج ملف APK. محاولة اتصال npm بالإنترنت فشلت برسالة `EAI_AGAIN`، لذلك لا تتوفر حزم React Native / Expo المطلوبة لاختبار Metro أو بناء Android في هذه البيئة. ملفات التطبيق و`eas.json` جاهزة للمتابعة على جهاز لديه إنترنت وبيئة بناء مؤهلة.
